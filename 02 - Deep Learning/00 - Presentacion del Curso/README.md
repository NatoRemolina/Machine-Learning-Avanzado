## Bienvenida y descripción (diap. 3)
- Quinto módulo del programa MLDS.
- Se aprenderán los conceptos fundamentales del aprendizaje profundo con Python y librerías especializadas; arquitectura y entrenamiento de redes neuronales; modelos pre-entrenados del estado del arte en análisis de imágenes y modelos de lenguaje.

## Meta (diap. 4)
- Abordar temas y conceptos fundamentales del *Deep Learning* por medios computacionales.
- Aspectos de entrenamiento de redes: desde la arquitectura de los modelos, pasando por metodología y técnicas de entrenamiento.
- Trabajo con modelos predefinidos y pre-entrenados (estado del arte) en: análisis de imagen, modelos de lenguaje, clasificación de texto y modelos generativos.
- Todo mediante Python y sus librerías especializadas para Deep Learning.

## Objetivos de aprendizaje (diap. 6–7)
Al finalizar el módulo usted deberá ser capaz de:
1. Entender los conceptos fundamentales del Deep Learning y la metodología asociada a su uso y aplicaciones.
2. Conocer y aplicar los fundamentos de programación para el uso y desarrollo de modelos de redes neuronales profundas mediante Python y sus librerías especializadas.
3. Entender las técnicas de preprocesamiento y entrenamiento o ajuste fino de modelos de Deep Learning supervisados y no supervisados, usando Python y TensorFlow.
4. Aplicar técnicas de aprendizaje profundo en tareas supervisadas o no supervisadas relacionadas con tareas clásicas como análisis y procesamiento de imagen y análisis de texto.

## Conceptos previos (diap. 8)
- Programación básica en Python.
- Uso de librerías científicas: **NumPy, matplotlib, scikit-learn, pandas**.

## Habilidades y competencias (diap. 9–12)
- **Saber:** conceptos fundamentales de redes neuronales profundas; dominar redes convolucionales; entender modelos profundos para análisis de texto (RNN y Transformers); conocer otros modelos para aprendizaje autosupervisado y generativo.
- **Saber hacer:** diseñar e implementar modelos de DL con librerías de Python y entrenarlos con grandes conjuntos de datos; evaluar rendimiento y ajustar hiperparámetros (precisión y eficiencia); usar modelos pre-entrenados para problemas específicos (clasificación de imágenes, PLN); visualizar resultados y comunicarlos mediante visualizaciones y presentaciones.
- **Saber ser:** curiosidad y mente abierta para aprender constantemente; analizar y evaluar datos y resultados de forma crítica y objetiva, y tomar decisiones informadas para mejorar modelos y algoritmos.
