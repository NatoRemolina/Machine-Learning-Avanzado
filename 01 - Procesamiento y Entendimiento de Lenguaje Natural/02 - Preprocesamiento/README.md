# Unidad 2 — Preprocesamiento

**Publicada en Classroom:** 21 de agosto de 2026

## Temas
- **Expresiones regulares:** conceptos, funciones de `re`, identificadores de caracteres, cuantificadores, operadores y grupos
- **Introducción a spaCy:** qué es, modelos, *pipeline*, objetos y componentes
- **Preprocesamiento de texto:** carga de datos, estructura típica, tokenizado, filtrado de palabras, lematización, normalización de caracteres, modificación de la grafía y limpieza con *regex*

## Objetivos (de la presentación del curso)
1. Describir la relación entre un proyecto de NLP y uno de ciencia de datos o *machine learning*.
2. Entender las expresiones regulares para búsqueda y limpieza de texto.
3. Seleccionar la estrategia de preprocesamiento más adecuada para distintos datos textuales.
4. Usar spaCy y entender sus módulos y componentes básicos.
