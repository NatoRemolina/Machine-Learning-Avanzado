# Unidad 1 — Introducción a NLP

**Publicada en Classroom:** 17 de agosto de 2026

## Temas
- **Manejo de archivos:** sistema de archivos con `os`, archivos planos y archivos JSON
- **Obtención de textos:** extracción de texto de PDF, de imágenes con OCR y de la web (*web scraping*)
- **Manipulación de *strings*:** tipos de *strings*, operaciones y métodos

## Objetivos (de la presentación del curso)
1. Describir los conceptos generales del NLP, sus retos y los tipos de aplicaciones actuales.
2. Usar librerías y utilidades de Python para obtener información textual.
3. Manipular textos como cadenas en Python: operaciones, formatos y búsquedas exactas y por patrones.
